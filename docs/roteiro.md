# Roteiro de estudo

[← Índice da documentação](README.md)

Do que aparece em quase toda vaga .NET para o que só pesa em vagas avançadas. Cada etapa termina com algo publicado.

1. **Fundação** (Agora até jan/2027): Terminar a Fase 1 do setup; C#/.NET, SQL, Git, Docker Compose e testes. Entregar o primeiro sistema AM com CI no GitHub Actions. Isso já atende a maioria das vagas júnior .NET.
2. **Nuvem Azure** (Fev a abr/2027): AZ-900 e deploy do AM Kaixara no Azure com Terraform, Key Vault e OIDC. Começar a observabilidade com OpenTelemetry e Aspire.
3. **IA aplicada** (Mai a jul/2027): RAG com pgvector dentro de um sistema AM, um servidor MCP próprio e os agentes do Claude Code. É o tema que mais cresce e conversa com o AM Projeta.
4. **Distribuído e plataforma** (Ago a out/2027): RabbitMQ, autenticação OIDC, Kubernetes local (kind) e Grafana. AZ-204 no fim.
5. **Linux e segurança** (Em paralelo, 1 a 2 noites por semana): Arch em VM, depois no segundo NVMe; Kali em VM para a trilha Security+ → eJPT. Já está no seu plano; aqui só ganha lugar na máquina.
6. **Segunda nuvem e sênior** (2028): AWS (Cloud Practitioner → Developer Associate), Kafka, Windows Server/AD para OSCP, homelab com Ubuntu Server.
