# Roteiro de estudo

[← Índice da documentação](README.md)

Do que aparece em quase toda vaga .NET para o que só pesa em vagas avançadas. Cada etapa termina com algo publicado.

1. **Fundação** (Agora até jan/2027): Terminar o núcleo do setup; C#/.NET, SQL, Python, Git, Docker Compose e testes. Entregar o primeiro sistema AM com CI no GitHub Actions. Isso já atende a maioria das vagas júnior .NET.
2. **Nuvem Azure** (Fev a abr/2027): AZ-900 e deploy do AM Kaixara no Azure com Terraform, Key Vault e OIDC. Começar a observabilidade com OpenTelemetry e Aspire.
3. **Engenharia de dados** (Fev a jun/2027, 1 noite por semana): Data Engineering Zoomcamp usando os seus próprios dados de venda: DuckDB, dbt sobre o banco de métricas, Airflow agendando, PySpark local. Fecha com o painel de lucro lendo modelos dbt testados.
4. **IA aplicada** (Mai a jul/2027): RAG com pgvector dentro de um sistema AM, um servidor MCP próprio e os agentes do Claude Code.
5. **IA profunda e treino** (Ago a dez/2027): PyTorch e redes neurais do zero (Zero to Hero, fast.ai), Transformers e o curso de LLM da Hugging Face. Primeiro fine-tuning QLoRA de um 8B no Kaggle com um dataset só seu, avaliação contra o modelo base e o resultado rodando no Ollama. A matemática da licenciatura (álgebra linear, cálculo, probabilidade) entra aqui.
6. **Linux e segurança** (Em paralelo, 1 a 2 noites por semana): Kali em pendrive com persistência e em VM para a trilha Security+ → eJPT; Arch instalado num pendrive ou SSD USB, depois no segundo NVMe.
7. **Distribuído e plataforma** (2028): RabbitMQ e Kafka, autenticação OIDC, Kubernetes local (kind). AZ-204.
8. **Segunda nuvem e sênior** (2028): AWS (Cloud Practitioner → Developer Associate), Windows Server/AD para OSCP, homelab com Ubuntu Server.
