# Fora do setup

[← Índice da documentação](README.md)

| Item | Por que ficou de fora |
|---|---|
| Dual boot no SSD atual | Risco de perder dados; o Arch vai para o segundo NVMe. |
| Kali como sistema principal | É caixa de ferramentas de pentest, não ambiente de dev. Fica em VM. |
| OpenClaw | Histórico sério de instâncias expostas e execução de código não confiável. |
| Treinar um 8B na GTX 1650 | O QLoRA de 8B pede no mínimo 6 GB de VRAM e a placa tem 4 GB. O 8B roda no notebook (GPU + RAM); o treino dele vai para o Kaggle ou GPU alugada. |
| Bun, Hono, Rust, Tauri, gRPC | Rejeitados por você para o Aura. |
| Mobile nativo (Kotlin, Swift, Flutter) | Fora do foco dos 12 meses. |
| Postman, IDEs pagas, SaaS pagos | Você prefere open source; Bruno, DBeaver e VS Code cobrem. |
